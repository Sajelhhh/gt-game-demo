# Character artwork

These three original character images were generated for Shadow Sprout with
OpenAI image generation on 2026-08-09, then locally chroma-keyed, cropped, and
optimized as transparent PNG files:

- `shadow-sprout.png`: forest sprout knight player character
- `thorn-beetle.png`: amber patrol enemy
- `crystal-bat.png`: violet chase enemy

The prompts requested original, family-friendly storybook pixel-art-inspired
characters with no resemblance to an existing franchise. No third-party game
art or copyrighted character reference was used.
